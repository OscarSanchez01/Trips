# Trips
En esta web, podremos buscar una ciudad de españa y podremos ver el tiempo en esa ciudad y un listado de los hoteles, hostales
y pensiones de la ciudad.

Antes de empezar a ejecutar cualquier cosa, debemos acceder a la página: https://cors-anywhere.herokuapp.com/corsdemo
y desde ella activar la prueba demo para poder utilizar las APIS.
